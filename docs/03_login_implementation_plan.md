# 로그인 화면(Login Screen) 구현 계획

사용자께서 제공해주신 새로운 로그인 화면 디자인을 바탕으로 `lib/screens/login_screen.dart`를 본격적으로 구현하기 위한 계획입니다.

> 아래 구현 계획을 검토하시고 승인(진행해줘!)해 주시면 바로 코드 작성을 시작합니다.
> (승인 시, 이 계획서는 약속드린 대로 `AIPO/docs/03_login_implementation_plan.md`로도 복사하여 보관해 두겠습니다.)

## Proposed Changes

### [MODIFY] `lib/screens/login_screen.dart`
현재 빈 화면(Dummy)으로 존재하는 로그인 화면을 다음 구조로 전체 재작성합니다.

1. **상단 타이틀 영역**
   - 텍스트: "환영합니다!" (매우 크고 두꺼운 강조 폰트)
   - 서브 텍스트: "AIPO의 개인화된 맞춤형 서비스를 경험해 보세요." (회색, 일반 폰트)

2. **입력 폼(Input Fields) 영역**
   - **아이디 입력 필드**: 테두리 선이 없고, 연회색 배경(`Color(0xFFF5F6F8)`)과 라운드 처리된 깔끔한 디자인 텍스트 필드.
   - **비밀번호 입력 필드**: 아이디와 동일한 디자인에 우측 끝에 '눈 모양 아이콘(비밀번호 숨기기/보이기)'을 배치.

3. **회원가입 유도 영역**
   - 텍스트 폼 바로 아래에 "아직 계정이 없으신가요? **회원가입**" 문구를 배치.
   - 앞쪽은 회색 일반 폰트, "회원가입" 부분은 파란색 두꺼운 폰트로 클릭 가능한 형태로 구현 (`RichText` 활용).

4. **하단 액션 영역**
   - 바닥에 고정되는 "로그인" 메인 버튼 (파란색 배경, 라운드 처리).
