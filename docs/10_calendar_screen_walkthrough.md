# 일정(달력) 화면 커스텀 렌더링 완료

새로운 하단 탭인 **"일정 (공모주 캘린더)"** 화면(`lib/screens/calendar_screen.dart`) 파일 생성이 완벽하게 완료되었습니다.

## 1. 5일제(평일 전용) 그리드 달력 구현
플러터의 기본 달력 라이브러리들은 무조건 주말을 포함한 7일을 뱉어내기 때문에, 우리만의 아주 똑똑하고 컴팩트한 그물망(Grid) 달력을 커스텀으로 짜내었습니다.
- **수학적 계산:** 2026년 4월 1일이 수요일인 점을 역추적하여, "월,화" 칸은 빈칸(Empty Cell)으로 두되 주말(토,일)에 해당하는 날짜들은 배열에서 원천 제외하도록 로직을 작성했습니다.
- 그 결과, 화면을 꽉 채우는 세로형 직사각형 `월~금` 열이 예쁘게 렌더링되었습니다. 
- 선택된 날(8일)은 배경이 앱 스탠다드 색상인 파란색 동그라미로 바뀌며 글자는 하얗게 토글됩니다.

## 2. 일정 뱃지 (미니 알약) 마크업
캘린더 칸 안에 글자를 구겨 넣으면 레이아웃이 무너지기 십상입니다. 이를 막기 위해 이벤트 정보에 `maxLines: 1` 조치와 `TextOverflow.ellipsis`를 부여하여 화면이 절대 깨지지 않고 꽉 들어차면 "스페이스테..." 로 자동 말줄임되도록 안전장치를 넣었습니다.

## 3. 하단 스펙 카드 동적 변화 기능
현재 8일, 10일, 14일, 15일에 하드코딩 데이터를 심어 두었습니다. (디자인에 나온 이미지 그대로요!)
- 8일을 클릭하면 아래에 미래에셋(92점)과 신영증권(85점) 정보 박스가 아름답게 나타납니다.
- 아무 일정이 없는 날(예: 1일, 2일)을 탭해보시면 아래 카드가 사라지고 **"해당 날짜에는 일정이 없습니다."** 라는 피드백이 자연스럽게 뜨도록 생동감을 주었습니다.

## 테스트 가이드라인
앱 하단 탭 바에서 `홈` 옆에 있는 두 번째 버튼인 캘린더 모양 **[일정]** 을 클릭해 보세요! 바로 새로운 페이지로 진입하게 됩니다. (오류 여부 검증 또한 `flutter analyze`를 통해 100% 무결점 통과했습니다.)
