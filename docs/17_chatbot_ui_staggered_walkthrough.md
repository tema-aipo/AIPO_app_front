# 🤖 챗봇 화면 UI (애니메이션 탑재) 개발 완료

유저가 공모주 관련 질문을 던질 수 있는 메인 대화창이자, 앱의 마지막 빈 공간이었던 세 번째 탭 **[챗봇 화면(`ChatbotScreen`)]** UI 구축을 성공적으로 완료했습니다!

## 주요 구현 사항 (화면 기믹)

### 1. 나에게 말을 거는 동적 인사말
- 로그인 처리를 담당했던 지난번의 `AuthManager` 데이터를 읽어옵니다.
- 유저 아이디와 설정해 둔 현재 성향에 따라 "안녕하세요, **AIPO 매니아** 님!", "나의 **'안정형'** 성향에 맞는 이번 주 공모주는?" 처럼 텍스트가 유기적으로 변하도록 묶어두었습니다. 

### 2. 살아 숨 쉬는 화면 (Staggered Animation)
- 화면에 아무런 움직임 없이 텍스트가 '띡' 뜨는 구조를 벗어나, 훨씬 고급스러운 앱 느낌이 나도록 **스태거 애니메이션(Staggered Animation)** 을 삽입했습니다.
- 유저가 '챗봇' 탭을 처음 눌러 입장할 때:
  1. 먼저 "안녕하세요~" 인사말이 0.1초 만에 스르륵 위로 올라오고,
  2. "추천 질문" 소제목이 뒤를 이어 부드럽게 나타나며,
  3. 그 아래에 있는 하얀 테두리 카드(질문 버튼) 4개가 `도미노처럼 순차적으로` 파도타기 하듯 위로 0.1초 간격으로 밀려 올라옵니다!
- 매우 우아한 입장 효과를 내기 위해 단순한 코드 대신 `AnimationController` 와 커스텀 커브(`Curves.easeOutCubic`) 곡선을 사용했습니다.

### 3. 부드러운 머티리얼 반사 (InkRipple) 이펙트
- 시안의 요구사항대로 질문 탭의 자동입력까지는 아직 구현하지 않았지만, 카드를 누를 때 손가락에서부터 부드럽게 퍼져나가는 `터치 물결 피드백(터치 액션)`을 은은하게 달아두어 누르는 맛을 살려 두었습니다.

### 4. 하단 입력 바 배치 완료
- 키보드가 올라올 것을 대비해 유동적인 배치와 모서리가 둥근 텍스트필드, AIPO 컬러인 새파란 전송 버튼을 안정적으로 이식했습니다.
