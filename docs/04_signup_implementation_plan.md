# 회원가입 화면(Signup Screen) 구현 계획

사용자께서 제공해주신 새로운 "회원가입 1단계(정보입력)" 화면 디자인을 바탕으로 `lib/screens/signup_screen.dart`를 본격적으로 개발하기 위한 계획입니다.

## User Review Required

> [!IMPORTANT]
> 아래 계획을 확인하시고 승인(진행해줘)해 주시면 바로 코딩을 시작합니다.
> 승인해 주시면 이 문서는 즉시 `docs/04_signup_implementation_plan.md`로 안전하게 백업 및 보관됩니다!

## Proposed Changes

### [MODIFY] `lib/screens/signup_screen.dart`
현재 빈 화면(Dummy)으로 존재하는 회원가입 화면을 다음 구조로 재작성 및 구현합니다.

1. **상단 앱바 (AppBar)**
   - 좌측에 뒤로 가기(←) 버튼 배치.
   - 중앙 타이틀: "회원가입" (검은색 두꺼운 폰트).

2. **진척도 표시기 (Progress Stepper)**
   - 가로형 컴포넌트로 제작.
   - `1 (정보입력 - 파란색 활성화)`, `2 (투자성향검사 - 회색 비활성화)`, `3 (완료 - 회색 비활성화)` 를 선으로 연결하는 구조의 UI 컴포넌트로 구현합니다.

3. **입력 폼 영역 (Forms)**
   - **이름 / 이메일**: 일자형 회색 라운드 배경 텍스트 필드.
   - **아이디 & 중복확인 버튼**:
     - `가로(Row)` 배열을 사용하여 왼쪽에는 짧은 아이디 텍스트 필드를 두기.
     - 오른쪽에는 메인 파란색 여백을 가진 "중복확인" 버튼(`ElevatedButton`) 배치.
   - **비밀번호 / 비밀번호 확인**:
     - 로그인 화면과 동일한 스타일.
     - 우측 눈 모양 아이콘 추가 (`StatefulWidget`으로 관리하여 각각 별도의 가리기/보이기 상태 설정).

4. **하단 액션 버튼**
   - 최하단에 "다음" 이라는 파란색 메인 버튼 배치. 키보드가 올라오면 자연스럽게 화면 밖으로 스크롤되도록 `SingleChildScrollView`를 조절합니다.
