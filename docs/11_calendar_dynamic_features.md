# "공모주 일정(달력)" 완전 동적 버전 연동 완료

이전 단순 형태(Mockup)의 캘린더에서 벗어나 말씀하신 5가지 기능 조건들이 모두 적용된, 실제 앱처럼 굴러가는 **동적 캘린더**가 완성되었습니다.

## 1. 전월/익월 빈칸 완벽 계산 채우기
> [!TIP]
> 더 이상 1일 앞부분과 월말 뒷부분이 하얗게 비어있지 않습니다!

달력을 그릴 때 1번 줄의 요일 계산을 통해 남는 앞자리엔 **"저번 달의 월화수목금" 날짜**를 회색으로 은은하게 그리고, 뒷부분에는 **"다음 달의 요일" 날짜**들을 밀어 넣었습니다. (물론 똑같이 토/일요일은 알아서 제외하고 넣어주는 똑똑한 커스텀 알고리즘입니다!) 

해당 날짜(회색)를 클릭하면 자동으로 화면 전체의 달력 연도/월이 클릭한 곳의 달로 이동합니다.

## 2. 클릭형 상단 카테고리 필터
상단에 써 있는 `수요예측, 청약, 상장` 글씨를 직접 탭(터치)해 보세요!
한번 눌리면 연한 회색으로 불빛이 꺼지며, 달력 안에 들어있는 해당 색깔의 뱃지들이 전부 숨겨집니다. 아래 상세 모록 카드에서도 즉시 사라집니다. 다시 켜면 나타나게 되며 이는 On/Off 스위치 (다중 필터) 방식으로 작동합니다.

## 3. 월(Month) Navigation
상단의 `< 2026년 4월 >` 에서 양쪽 화살표를 클릭시 즉각적으로 년/월을 이동할 수 있습니다. 

## 4. 리스트 라우팅 & 검색(돋보기) 모달창
- 이제 하단 카드를 터치하시면 즉시 이전에 우리가 만들어두었던 **`공모주 상세페이지`**로 스무스하게 애니메이션하며 넘어갑니다. 앱의 흐름이 연결되었습니다.
- 우측 상단의 `돋보기(검색)`를 터치하시면 요청하셨던 **팝업 모달창 (AlertDialog)** 이 친절하게 뜨며 "향후 데이터가 연결되면 열쇠 역할을 할 것"임을 알립니다.

이 모든 기능은 상태 관리(State Management)를 새롭게 뜯어고친 `calendar_screen.dart`의 성과입니다. 린트(Errors) 또한 단 하나도 없습니다.
