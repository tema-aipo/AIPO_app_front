# 공모주 상세 정보 화면(Detail Screen) 구현 계획

각 탭과 리스트에서 공모주를 터치했을 때 넘어오게 될 **"공모주 상세정보 화면"** 의 골격과 UI 컴포넌트를 설계합니다. 사용자님의 요청에 따라 데이터가 묶이는 위치(레이아웃)를 명확히 보여주되, 실제 숫자가 들어가는 상당수 항목을 **[데이터 연동 대기중..]** 으로 표기하는 하이브리드 목업 형태를 띱니다.

## User Review Required

> [!IMPORTANT]
> 아래 구조 계획을 검토하시고 **승인(진행해줘)** 해 주시면 바로 코딩을 시작합니다.
> 승인해 주시면 이 문서는 즉시 `docs/09_ipo_detail_screen_plan.md` 파일로 안전하게 백업 및 보관됩니다!

## Proposed Changes

### 1. [NEW] `lib/screens/ipo_detail_screen.dart` 생성
- **배경색 (Background):** 연한 회색(`AppColors.bgGray`)
- **앱바 (AppBar):** 좌측 뒤로 가기 버튼, 우측 찜하기(하트 아이콘).
- **스크롤 영역 (SingleChildScrollView):** 하단으로 길게 이어지는 모든 카드 뷰를 부드럽게 스크롤링.

#### [화면 구성요소 (Cards)]
모든 카드는 흰색 배경(`AppColors.white`)에 모서리가 둥글고 그림자가 살짝 들어간 형태를 가집니다.
1. **헤더 카드 (요약 정보):**
   - 상단 원형 아이콘 + 공모주명(`스페이스테크놀로지`) + 서브타이틀
   - 확정공모가, 주관사, 청약일 3단 리스트 
   - *일부 정보 연동 대기 텍스트 처리*
2. **AIPO 매력지수 카드:**
   - 타이틀 "AIPO 매력지수" & "92점" (파란색 거대 폰트)
   - 파란 음영 박스 안 안내문구: "매력지수 산정 근거" -> `[데이터 연동 대기중..]`
3. **기관 수요예측 결과 카드:**
   - 6개의 속성 리스트(경쟁률, 참여기관수 등). 
   - 우측 값 부분 모두 `[데이터 연동 대기중..]` 스타일 표기.
4. **청약 경쟁률 카드:**
   - 토글 버튼 그룹: (균등배정 / 비례배정)
   - 주요 텍스트: "예상 균등 배정 수량" + "1.2주" (디자인 확인용)
   - 통합 경쟁률 -> `[데이터 연동 대기중..]`
5. **청약 일정 카드:**
   - 수요예측일 -> 청약일(활성화/파란 점) -> 환불일 -> 상장일 
   - 세로 선으로 이어진 타임라인(Timeline) 디자인 커스텀 레이아웃.
6. **청약증거금 카드:**
   - 오렌지색 아이콘 + 증권사명
   - 최소 증거금액 -> `[데이터 연동 대기중..]`
7. **공모주 정보 카드:**
   - 시가총액, 비율 등 4가지 속성. -> `[데이터 연동 대기중..]`

### 2. [MODIFY] `lib/screens/home_screen.dart` (화면 연결)
- 홈페이지에 구현해둔 인기 공모주, 실시간 조회, 매력지수 카드를 `GestureDetector`(또는 `InkWell`)로 감싸서, 어떤 종목을 누르든지 방금 설계한 `IpoDetailScreen`으로 라우팅(`Navigator.push`) 되도록 연결점을 뚫어 놓습니다.

## Open Questions
- 뒤로 가기 연동 및 UI 레이아웃의 전반적인 배치가 완벽히 잡혀있습니다. 이대로 화면을 그리고 추후 API 파라미터만 던져주는 방식으로 개발하면 유지보수가 매우 좋을 구조입니다!

## Verification Plan
1. 구현 후 린트 오류 테스트 적용.
2. 홈 화면에서 종목 카드를 클릭 시 **상세 화면으로 부드럽게 넘어가지는지**, 상세 화면의 **카드가 디자인(배경색-카드색 등) 대비감 있게 예쁘게 출력되는지** 시각적으로 확인합니다.
