# 🔐 임시 로그인 기능 및 내 정보 데이터 연동 완료

우리가 예전에 만들어둔 **'온보딩 -> 로그인 화면'** 을 실제 기능처럼 동작하도록 강력한 전역 로그인 시스템(`Mock AuthManager`)을 입혀 앱의 진입 흐름을 완전체로 만들었습니다!

## 주요 변경 및 동작 내역

### 1. 첫 화면 라우팅 처리 (`main.dart`)
- 앱을 최초로 켜거나 새로고침하면 가장 먼저 로그인 상태를 확인합니다.
- 로그인되어 있지 않으면 **[온보딩 화면]** 을 맨 처음 보여주게 되고, "AIPO 시작하기" 를 눌러 **[로그인 화면]** 으로 자연스럽게 진입하게 됩니다.

### 2. 가상의 안전한 도어락 시스템 (`LoginScreen`)
- 로그인 화면에 보이는 '아이디'와 '비밀번호' 입력란에 **직접 키보드로 타건하여** 입력하고 버튼을 눌러야만 들어갈 수 있습니다.
- **[테스트용 임시 계정 규격]**
    - **ID:** `guest`
    - **PW:** `1234`
- 만약 틀린 글자를 칠 경우 들어가지지 않고, 빨간 경고창 대신 하단에 부드러운 스낵바가 뜹니다: `"아이디 또는 비밀번호가 일치하지 않습니다."`

### 3. 로그인 정보의 앱 내 동기화 (`MyPage` & `Profile` 탭)
- 로그인을 성공적으로 통과하면 드디어 익숙한 메인 홈 화면들이 나타납니다.
- **마이페이지 탭**으로 들어가보시면, 이전처럼 하드코딩된 '사용자 님'이 아닌 계정의 실 데이터(ex. `AIPO 매니아 님`, `#안정형`)가 출력되는 것을 확인할 수 있습니다!
- 프로필 카드를 눌러 진입한 **'내 정보'** 에도 위 로그인 아이디(`guest`) 정보가 이메일 주소 등과 함께 고스란히 연동됩니다.

### 4. 로그아웃을 통한 매끄러운 추방 기능
- 마이페이지 하단부의 **[로그아웃]** 메뉴를 누르고 팝업에서 **[확인]** 을 치는 즉시, `AuthManager`에 있던 유저 정보가 증발하고 앱의 초입인 로그인 뷰로 스무스하게 튕겨나옵니다.

이제 에뮬레이터를 새로고침하시거나 런타임을 재시작하시면, 온보딩과 테스트 계정 로그인의 신세계를 맛보실 수 있습니다.
