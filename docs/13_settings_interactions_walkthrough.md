# ⚙️ 마이 페이지 '설정' 상호작용 및 서브 화면 구현 완료

요청하신 세 가지 디자인 시안과 직접 제안한 로그아웃 팝업 1종을 모두 마이 페이지 **설정 탭**에 연결해 두었습니다.

## 구현 상세 내역

### 1. `내 정보` 페이지 이동 (Profile Screen)
- 설정 탭의 맨 우측 상단 박스(`사용자 님` 클릭 유도 영역)를 누르면 부드럽게 새로 추가된 **`내 정보`** 화면(Profile Screen)으로 라우팅됩니다.
- 시안 1번에 맞게 <이름, 아이디, 이메일> 부분은 수정되지 않음을 암시하는 **자물쇠 뱃지(`Icons.lock_outline`)** 아이콘과 함께 읽기 전용 상태로 보여집니다.
- 비밀번호 변경 파트에는 **현재 / 새 비밀번호 / 확인란** 총 3개의 비밀번호 보안 입력칸(`obscureText`)을 구현했으며 누르면 파란색 포커싱이 됩니다.

### 2. 알림 설정 하단 시트 (Bottom Sheet)
- **`알림 설정`** 메뉴를 누르면 화면 아래서 부드럽게 올라오는 모달 바텀 시트를 띄웁니다.
- **로컬 스위치 상태 관리:** iOS스러운 둥글둥글한 `CupertinoSwitch` 디자인을 가져다 놓았습니다. "청약 일정 알림"과 "상장일 알림" 옆의 토글 스위치를 작동시키시면 즉시 파란색(On)/회색(Off)으로 부드럽게 애니메이션하며 바뀝니다!

### 3. 회원탈퇴 하단 시트 (Bottom Sheet with Keyboard)
- 빨간색 텍스트의 **`회원탈퇴`** 버튼을 누르시면, 시안대로 무거운 알림을 띄우는 하단 시트가 나타납니다.
- 특히 이 창에서는 "비밀번호 입력란" 텍스트필드(`TextField`)가 활성화되며, 누르면 키보드가 올라옴과 동시에 **창이 키보드에 가려지지 않도록 빈 화면의 높이가 동적으로 조절(`viewInsets.bottom` 계산)**되는 고급 레이아웃 스킬을 적용했습니다. 입력란 우측엔 가시성 체크용 '눈 모양' 아이콘도 놓여있습니다.

### 4. 로그아웃 팝업창 (AlertDialog)
- **`로그아웃`** 메뉴 탭 시, 화면 한가운데에 경고창 다이얼로그가 이쁘게 렌더링되며, 둥근 창 안에서 `< 취소 / 확인 >` 옵션을 선택할 수 있게 만들어두었습니다.
