# 회원가입 2단계(투자성향검사) 화면 구현 계획

사용자께서 전달해주신 3장의 이미지를 바탕으로, `lib/screens/signup_step2_screen.dart`에 "투자성향검사" 화면을 본격적으로 개발하기 위한 계획서입니다.

> 승인해 주시면 이 문서 또한 `docs/05_signup_step2_plan.md`로 안전하게 백업 및 보관됩니다!

## Proposed Changes

### [MODIFY] `lib/screens/signup_step2_screen.dart`
현재 더미 파일로 놓아둔 해당 스크린을 상태 관리 위젯(`StatefulWidget`)으로 변경하고 전체 UI를 구축합니다.

1. **상단 UI 및 진척도 표시기**
   - 상단 앱바 타이틀은 "회원가입" 유지.
   - **스텝 표시기**: `2. 투자성향검사` 부분의 텍스트와 원을 파란색으로 활성화하고 1번과 3번은 회색으로 변경.
   - **질문 진행도(Progress Bar)**: 스텝 바 하단에 'N / 6' 이라는 파란 텍스트와 함께 진행 바(가로선)가 질문 인텍스에 맞춰 파란색으로 채워지는 UI 추가.

2. **설문 데이터 모델링 및 질문-선택지 영역**
   - 제공해 주신 3개의 질문과 선택지를 코드 내에 배열(List)로 저장해 관리합니다. 
   - 사용자가 선택한 선택지는 파란색 테두리와 파란색 글씨, 아주 연한 파란색 배경(`Color(0xFFE5F0FF)` 계열)으로 스타일이 바뀌며 체크되도록 구현합니다. (선택 안 된 항목은 기존 폼과 동일한 연회색 배경)
   - *아직 알려주시지 않은 4~6번 질문은 임시(Dummy) 텍스트로 채워 넣고, 나중에 제공해 주시면 내용을 쉽게 교체할 수 있도록 구성합니다.*

3. **하단 액션 영역 패턴**
   - **Q1 화면**: `다음` 파란 버튼 + 우측 상단 `스킵하기`.
   - **Q2 ~ Q6 화면**: `←` (이전 질문 가기) 아이콘 버튼 + `다음` 꽉 찬 파란 버튼 + 우측 상단 `스킵하기`.
