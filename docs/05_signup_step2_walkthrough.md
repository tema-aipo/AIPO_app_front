# AIPO 회원가입 화면(Signup 2단계) 구현 결과

승인해 주신 계획에 맞춰 '투자성향검사' 화면의 전체 UI와 6개의 질문 상태 관리 로직을 모두 구현 완료했습니다. 약속드린 대로 이 결과 문서는 `docs/05_signup_step2_walkthrough.md`로 백업됩니다.

## 1. 진행도(Progress) UI 및 라우팅 정리
- **진척도 표시기(Stepper):** 1번은 회색(이전 완료 단계), 2번은 파란색(현재 단계)으로 변경했습니다. 왼쪽 상단 `←` (AppBar 백 버튼)을 누르면 회원가입 1단계로 되돌아갑니다.
- **파란색 스탯 진행바:** 우측의 파란색 `1 / 6` 숫자와 함께 화면 가로 길이에 맞추어 파란색 게이지(`LinearProgressIndicator`)가 자연스럽게 차오르는 애니메이션 효과를 적용했습니다.

## 2. 설문 데이터 모델링 및 선택지 애니메이션
- `SurveyQuestion` 모델 클래스를 설계하여, 남은 질문 3개가 확정되면 코드 복붙 하나만으로 쉽게 내용을 완성할 수 있도록 유연하게 설계했습니다. (현재 4~6번은 준비 중이라는 문구로 대체된 상태입니다)
- 4개의 선택지 버튼을 커스텀 디자인했습니다. 사용자가 터치하면 즉시 부드럽게 연초록(아주 옅은 파란색) 배경 및 파란색 테두리로 스타일이 갱신됩니다.

## 3. 강력한 하단 네비게이션 제어
승인해주신 로직에 입각하여 디테일을 살렸습니다.
- **유효성 검증(Validation):** 선택지를 1개라도 누르지 않으면 하단의 `다음` 버튼은 클릭할 수 없는 완전한 회색 상태(`Color(0xFFE0E0E0)`)로 진입이 막힙니다. 아무거나 터치하는 순간 버튼이 진한 파란색으로 활성화됩니다.
- **이전문항 가기 화살표:** Q1에서는 나타나지 않고, Q2부터 좌측 하단에 파란색 `←` 화살표가 등장합니다. 누르면 답안을 유지한 채 이전 문제로 돌아갑니다.
- **스킵하기:** 유효성 검사를 무시하고 바로 다음 문제로 넘겨주는(Skip) 기능을 스킵 텍스트에 연동했습니다.
