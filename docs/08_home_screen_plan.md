# 메인 홈 화면(공모주 목록) 및 하단 탭바 구현 계획

전달해 주신 홈 화면 디자인을 바탕으로 본격적인 메인 진입 화면(`lib/screens/main_screen.dart` 및 `home_screen.dart`)을 개발하기 위한 계획서입니다. 사진에 포함된 복잡한 시각 요소들을 구조화하여 깔끔하게 조립하겠습니다.

## User Review Required

> [!IMPORTANT]
> 아래 계획을 검토하시고 **승인(진행해줘)** 해 주시면 홈 화면 전체 코딩을 시작합니다. 
> 승인해 주시면 이 문서는 즉시 `docs/08_home_screen_plan.md` 파일로 안전하게 백업 및 보관됩니다!

## Proposed Changes

### 1. [MODIFY] `lib/screens/main_screen.dart` (하단 네비게이션)
현재 더미(임시) 텍스트만 있는 `MainScreen`을 4개의 탭을 관리하는 **뼈대 화면**으로 변경합니다.
- **하단 탭바 (`BottomNavigationBar`):** 
  - 홈(Home, 활성화 시 파란색)
  - 일정(Calendar)
  - 챗봇(Chat)
  - 마이(Person)
- 탭 클릭 시 화면이 전환되는 상태(State) 로직을 추가하며, 0번째 인덱스는 새로 만들 `HomeScreen`을 띄웁니다.

### 2. [NEW] `lib/screens/home_screen.dart` (본문 UI)
사진의 모든 내용을 담을 홈 화면을 신규 생성합니다. 

#### [헤더 영역]
- 최상단 안전 영역(`SafeArea`)에 유저의 투자 성향을 나타내는 태그(`[#안정형]` 파란 배경/글씨)와 우측에 검색 돋보기 아이콘을 배치합니다.
- 대제목: "현재 가장 주목받는 공모주" (방금 만든 디자인 시스템의 굵은 폰트 적용)

#### [섹션 A: 인기 공모주]
- 부제목: "인기 공모주" + 작고 연한 글씨 "조회수 기준"
- 레이아웃: 가로로 스와이프 가능한 리스트 뷰(`ListView.builder` horizontal) 구현.
- 데이터 모델: 순위(`#1`), 종목명(`바이오메디컬`), 조회수(`3,542 조회`)를 담은 연파랑색 네모 상자 카드 구현.

#### [섹션 B: 실시간 조회 급등]
- 부제목: "실시간 조회 급등"
- 레이아웃: 세로 고정 3칸 리스트. 
- 데이터 모델: 등수(1,2,3 파란 점/글자), 종목명, 상승률(`+125%` 빨간 글씨), 조회수(회색)

#### [섹션 C: 공모주 매력지수]
- 부제목: "공모주 매력지수"
- **조회 필터 칩:** "최근 상장순"(활성화 시 어두운 회색), "청약 예정순", "관심 종목순" 가로형 버튼 리스트.
- **매력지수 카드:** 
  - 백색의 둥근 모서리와 얇은 그림자를 가진 카드 목록.
  - 파란색 원형 점 + 파란색 `92점` 점수 라벨, 종목명, 상장일(회색), 그리고 우측에 가벼운 회색 화살표(`→`) 아이콘 배치.
