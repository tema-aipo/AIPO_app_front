# 온보딩 화면 2차 UI/라우팅 수정

사용자의 추가 피드백을 반영하여 온보딩 화면의 하단 UI를 간소화하고 라우팅 기능을 수정했습니다.

## 주요 변경 사항

- **라우팅 경로 변경**: 기존에는 `AIPO 시작하기` 버튼과 `로그인` 텍스트 버튼이 분리되어 있었고 시작하기 버튼이 `MainScreen`으로 향하고 있었습니다. 이제 `AIPO 시작하기` 버튼을 누르면 바로 `LoginScreen`으로 넘어가도록 `Navigator.push` 설정을 변경했습니다.
- **불필요한 텍스트 버튼 삭제**: 하단에 위치했던 '이미 계정이 있으신가요? 로그인' 이라는 텍스트 영역을 시각적 간결함을 위해 코드에서 온전히 제거했습니다. `Scaffold`의 하단 여백은 깔끔하게 정리해 유지했습니다.

Hot Reload를 통해 화면 상에서 로그인 텍스트가 사라지고 시작 버튼만 남아있는 것을 바로 확인하실 수 있습니다.
