# 회원가입 3단계(가입 완료) 화면 구현 계획

사용자께서 전달해주신 4장의 완료 화면(안정형, 공격형, 중립형, 스킵형) 이미지를 바탕으로 `lib/screens/signup_step3_screen.dart`를 본격적으로 개발하기 위한 계획서입니다.

## Proposed Changes

### [MODIFY] `lib/screens/signup_step3_screen.dart`
현재 더미 텍스트만 있는 완료 화면을 실제 결과 화면으로 변경합니다.

1. **상단 및 스텝 표시기 (`Stepper`)**
   - 상단 앱바(`AppBar`)에는 뒤로 가기(`←`) 버튼을 없앱니다. (이미 가입 완료되었으므로 이전 창으로 가는 것을 막음)
   - 스텝 플로우 컴포넌트에서 `1, 2`단계를 회색으로 흐리게 처리하고, `3. 완료`를 진한 파란색으로 활성화시킵니다.

2. **완료 메시지 및 카드 뷰 (`Result Card`)**
   - 상단 텍스트: "환영합니다!\n회원가입이 완료되었습니다 🎉"
   - 중앙에 그림자가 들어간 둥근 모서리의 백색 대형 카드를 배치합니다.

3. **결과 유형 분기 처리 (`UI State`)**
   - 말씀하신 대로 현재 백엔드 로직이 없으므로, 기본적으로 **[안정형]** 디자인 카드를 보여주도록 구성합니다.
   - 단, 2단계에서 유저가 "스킵하기"를 누르고 넘어온 상황을 판별하기 위해 스크린 생성자에 `bool isSkipped` 파라미터를 추가합니다.
   - `isSkipped`가 `true`일 경우, 4번째 사진처럼 **[분석 대기중]** 텍스트와 회색 해시태그(`#기본설정` 등)가 담긴 스킵 전용 디자인 카드를 렌더링합니다.

4. **하단 액션 영역**
   - 최하단에 "AIPO 시작하기" 메인 파란색 버튼을 배치하여 누르면 현재 준비되어있는 임시 메인 페이지(`MainScreen`)로 진입하게 됩니다.

### [MODIFY] `lib/screens/signup_step2_screen.dart`
- 2단계 로직에서 3단계로 넘어갈 때, `스킵하기` 버튼을 누르면 `isSkipped: true` 파라미터를 전달하도록 네비게이션 로직을 한 줄 수정합니다.
