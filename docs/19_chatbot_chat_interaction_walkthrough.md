# 🚀 AIPO 챗봇 실시간 대화 모드(채팅) 및 평가 UI 개발 완료

이전까지 인사말과 추천 질문만 보여주던 대기 화면 형식에서, 유저가 메시지를 보내면 즉각적으로 대화창 모드로 전환되는 **라이브 챗(Live Chat) 플랫폼**을 성공적으로 구축했습니다!

## 구현 및 테스트 가이드

### 1. 매끄러운 화면 전환 무빙
처음 챗봇 탭에 들어갔을 때는 기존과 동일하게 추천 질문 애니메이션 뷰가 나타납니다.
**추천 질문 중 하나를 터치하시거나, 밑에 있는 텍스트 상자에 아무말이나 적으시고 파란비행기(전송) 버튼을 클릭해보세요!**
- 1초 만에 화면 전체가 채팅 스크롤 뷰(`ListView`)로 싹 바뀌면서 내가 보낸 회색 말풍선이 우측에 생성됩니다!
- 사용자와 AI를 구별할 수 있도록 말풍선 모양이 카카오톡과 똑같은 비대칭 라운딩 형식으로 설계되었습니다.

### 2. 엄청난 디테일의 AI 요약 카드 및 툴바
제시된 시안을 완벽하게 재구성했습니다. 사용자가 `"스페이스테크놀로지..."` 키워드를 포함해서(또는 첫 번째 추천 질문을 눌러서) 질문하면,
- 1초 뒤 좌측에 파란색 `[ A ]` 아이콘과 함께 하늘색 요약 데이터 컨테이너(기관 경쟁률 등) + 텍스트가 달린 대형 말풍선이 뜹니다!
- **[복사 아이콘]** 누르기: 카드 우측 하단의 `복사하기` 아이콘을 누르시면, 내부 텍스트 전체가 클립보드에 깔끔한 형태로 저장되며 "클립보드에 복사되었습니다." 알림이 송출됩니다. 일반 메모장을 열어 붙여넣기 해보세요!

### 3. 평가(피드백) 폼의 마술 같은 애니메이션
- AI 답변 밑에 있는 **[엄지 내리기(👎 싫어요)]** 버튼을 누르시면, 그 아래로 은은하게 **"어떤 점이 아쉬우셨나요?" 평가 옵션 박스** 가 위아래로 길어지는 애니메이션을 내며 튀어나옵니다!
- 라디오 옵션(둥근 체크박스) 3개 중 하나를 눌러 고르신 뒤 **[제출하기]** 파란 글씨를 누르시면, 요청하신 대로 평가 박스가 다시 스르륵 접히며 깔끔하게 사라지는 마술을 볼 수 있습니다. (제출 완료 알림은 덤!)

이제 프론트엔드 레벨에서 구축할 수 있는 거의 모든 채팅 UI 기믹이 완성되었습니다! 앱이 정말 프로페셔널한 느낌으로 살아 숨 쉬고 있어요. 다음 개발 방향을 지시해주시면 달려가겠습니다!

-기능 추가 및 변경사항
1. 홈화면에서 검색버튼 눌렀을 때 화면 구성 및 흐름 생성
2. 달력 현재 날짜를 실제 날짜와 동일하게 작동하도록 구현
3. 좋아요/싫어요 버튼 다시 클릭했을 때 돌아오도록 변경
4. 채팅 목록에서 기록에 마우스를 올렸을 떄 핀 버튼과 삭제버튼이 나오도록 변경
5. 채팅 검색 구현
6. 모든 기록 삭제는 북마크 된 기록은 삭제 안되게 변경
